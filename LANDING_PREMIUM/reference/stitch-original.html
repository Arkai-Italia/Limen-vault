Direct Answers

Frequently Asked Questions

Do I need Obsidian installed?

No. LIMEN Vault is a standalone desktop app built on Tauri v2 and Rust. Its notes are standard Markdown with [[WikiLinks]], so opening them inside Obsidian is completely seamless—but strictly optional.

Do I need to write Markdown files?

No. You can import standard PDFs, Word documents, and spreadsheets. LIMEN automatically converts them into formatted Markdown source notes behind the scenes.

Is document search 100% offline?

Yes. BM25 lexical search and dense semantic vector embeddings run entirely on your local machine via an embedded daemon. No internet access is required to search your vault.

What platforms are supported?

The v7Mini pre-release is available today for macOS Apple Silicon (ARM64). Windows 11 preview support is under active development on the windows-build branch.
