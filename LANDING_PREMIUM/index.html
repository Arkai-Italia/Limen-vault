A FEW THINGS TO KNOW

Before you begin.

Do I need Obsidian or Markdown files?

No. Import documents in supported formats. LIMEN creates Markdown source notes internally. Obsidian is an optional way to work with those files.

Does everything work offline?

No. Configured local search and local answers can run locally. The current automatic classification and wiki pipeline uses OpenAI and requires internet access and an API key.

What can I download today?

The linked preview installer is for macOS Apple Silicon. Windows development is in preview; this page does not offer a final Windows installer.

Is the screenshot an actual interface?

Yes. The hero shows the running LIMEN Vault v7Mini application with an empty document library, captured on 11 October 2026. The internal sidebar currently displays “Vault V5”. The separate diagrams below are illustrations.

What is the software license?

The project license is pending a maintainer decision. View the repository for the latest status before reusing or redistributing the code.
