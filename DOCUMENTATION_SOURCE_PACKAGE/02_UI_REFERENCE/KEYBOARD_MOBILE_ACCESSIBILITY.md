# Accessibilità e Scorciatoie da Tastiera — LIMEN Vault v7Mini

## 1. Scorciatoie da Tastiera Supportate
- **`Invio` (Enter):** Invia il prompt digitato nella casella di chat quando non è premuto `Shift`.
- **`Shift + Invio`:** Inserisce un a-capo nel testo della domanda senza inviare.
- **`Esc` (Escape):** Chiude immediatamente qualsiasi modale aperta a schermo intero (Lettore Documenti `SCR-013`, Dettaglio Fonte `SCR-014` o Setup Wizard `SCR-002`).
- **`Tab` / `Shift + Tab`:** Navigazione sequenziale del focus visivo tra controlli, pulsanti e campi di testo.

## 2. Accessibilità Visiva e Contrasto
- **Palette Dark-Glass High-Contrast:** Fondo ardesia scurissimo `#0f172a` accoppiato a testo chiaro ad altissima leggibilità `#f8fafc` (rapporto di contrasto WCAG AAA superiore a 12:1).
- **Accenti di Stato Differenziati:** Colore verde lime `#77f117` per conferme e stati attivi; arancio ambra `#f59e0b` per stati di attenzione; rosso `#ef4444` per errori.
- **Supporto Screen Reader:** Pulsanti e controlli iconici provvisti di attributi semantici e `title` descrittivo.
- **Adattabilità Viewport Desktop:** Finestra ridimensionabile a partire da 1280×800 pixel fino a monitor ultrawide 4K senza perdita di elementi essenziali o sovrapposizioni.
